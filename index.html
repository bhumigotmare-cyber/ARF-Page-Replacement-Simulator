UNDERSTANDING THE ALGORITHM

How ARF Works

ALGORITHM GUIDE

Adaptive Replacement Frequency (ARF) is the educational page replacement approach implemented in this project. It considers both how frequently a page is used and how recently it was accessed.

ARF Concept

Frequency + Recency

It considers page usage frequency along with page age.

How does it work?

1. The simulator checks whether the requested page is already present in memory.

2. If present, it records a page hit and updates the page usage information.

3. If absent, it records a page fault and loads the requested page into memory.

4. If memory is full, the ARF heuristic considers frequency and age to select a page for replacement.

ARF Replacement Factors

Frequency

Usage Count

How many times a page has been accessed.
Age

Time Factor

How long ago a page was last accessed.

Important Note

In this project, ARF uses an educational heuristic based on frequency divided by age plus one. It is a project-specific approach and not a standard operating system page replacement algorithm.
